## 一、场外体系的由来

Mag场外体系源自早期纳斯达克场外粉单交易分析。为了防止"交易指标钝化"，体系把**低反身性**放在首位。如果不这样做，就会沦为Trading View上点赞过百却迅速失效的参考系统。

### 为什么要场外分析？

通过低反身性的数据源头减少被市场消耗的概率，规避集体效应的失真。

### 发展历程

- **2016-2017 起步**: 从 LocalBitcoins 场外一对一交易数据与纳斯达克粉单起家，借鉴医疗领域的 meta 聚类分析调参约一年半形成拟合
- **2017-2020**: 通过早期 OTC 交易拟合平台
- **2020 DeFi之夏后**:
  - 动态筛选所有池子
  - 给予不同权重和调参
  - 对场外巨鲸和高权重交易重点关注
  - 对高反身性池子剔除
  - 形成动态的新陈代谢数据取舍

### 三大核心指标

**1. 场外指数** - 描述场外资金的拉盘档位，和资金使用效率相关
- **1000** 是投产比 1:1 的均衡点：高于 1000，主力拉盘才有利可图；低于 1000，拉盘反而亏钱、主力缺乏动力
- 过低"几乎可以肯定不会大幅拉盘"
- 对操盘手而言，低场外指数意味着"资金使用效率极低"

**2. 爆破指数** - 描述短线场外的"油门"大小
- 从负变正的日期是**趋势企稳、可考虑进场的确认点**（注意：这不是"抄底"——体系坚决反对在下跌趋势里预测点位抄底）
- **200** 是重要阈值
- **0** 是负转正的关键节点

**3. 场外进退场期** - "操作情绪"的核心体现
- **进退场第一天**是入场和止盈最关键的参考
- 这是这套系统的**看家本领**

## 二、对市场的认知

价格只是表象。真正驱动行情的，是场外主力资金的进退。这一节讲的不是操作方法（见第三章），而是看待市场的一整套世界观——先看懂棋局，再谈落子。

### 场外指数：把复杂世界降到二维

现实里驱动价格的变量无穷无尽——政治、战争、情绪、资金……场外体系做的事，是把这团混沌**"拍成二维"**：政治变量、人心变量最终都收敛为几个数字——**场外指数、爆破指数、进/退场期**。

- **交易的本质，是从混沌中抽象出一个结构**。局部看，每一根 K 线都像布朗运动、随机漂移；但整体上，"从场外向场内溢出"的资金是有结构的。抓住那个结构，而不是去猜下一根 K 线。
- **这带来"认知复利"**：把这套降维语言用熟，就很难再被概念和故事忽悠。别人跟你讲基本面多好，你只需反问一句——**"为什么它没有体现在场外真实的买入上？"**
- 也正因如此，这套指标刻意**走场外、且不公开具体点位**：任何指标一旦被足够多人使用，就会因反身性而自我钝化（详见第一章）。要保持有效，就得和绝大多数人看到的东西不一样。

### 价格的两个动力源：对标链与谢林点

任何一个标的的价格，本质上只被两股力量驱动：**它对标的上游标的**，和**它自己的谢林点**。

```
美联储资产负债表 → 美股纳指 → 比特币 → 龙头币 → 山寨小币
```

- **对标链**：上游没有大异动时，价格回归自身谢林点；上游一旦剧烈波动，就优先跟随上游，等动能衰竭后再回归。比特币在纳指开盘的瞬间"跟锚"，就是因为大量套利资金把上游行情实时传导了下来。
- **谢林点：价格的引力中心**。它是场外多空真金白银投票、加权算出的力量平衡位，类似期权里的"最大痛点"。它**不是**阻力位/支撑位——阻力与支撑碰到会反弹；谢林点是**引力点**，在没有新流动性、新动能注入时价格被它吸附，而一旦接近、动能突破，往往会顺势加速、形成一段全新趋势。"为什么价格常被压在某个位置反复震荡"，答案就在这里。

### 动力学高于热力学：价格不等于基本面

这一轮行情最重要的范式转换，是**动力学（资金、流动性、情绪）压过了热力学（基本面、估值）**。"任何从基本面出发的，基本上在过去这一轮都死得差不多了。"

- **币圈尤其如此**：币价与项目团队的真实经营是脱钩的（成熟市场的监管禁止勾连），所以币价"只能来自流量和各种流动性"。好团队不等于好币——团队一流的项目，币价照样可以跌得最惨。"买股票就是买公司"只适用于有真实业务和监管托底的美股，**不适用于币圈**。
- **河流与缸的比喻**：只有当流动性充裕、"整条河都是满的甚至要溢出"时，比较各个"缸"（标的）的大小才有意义；一旦流动性枯竭，就只能研究动力学、流动性和情绪。
- **大资金能用衍生品结构强行扭曲现货价格**。冲突、封锁海峡的当天原油却只微涨，与基本面完全不符——这是资金近端压价、远端布局的结果。而**压制不会消灭能量，只会压缩势能**，压得越久，最终释放得越猛。
- 因此，**学会"用场外看场内"就等于开了高维之眼**：场内在涨、而场外并无新增资金流入，这种上涨就不可持续。
- **估值的三个台阶**：能用市盈率（PE）稳定估值、且能自我回购的，是"脱虚向实"的成熟资产，有稳固的底；只能用市销率（PS）、仍在烧钱证明自己的（题材股、大量 AI 概念、强庄股），天生就是宽幅震荡，**任何交易信号在它身上都容易失效**——只能小仓位、用现货去碰，绝不上杠杆。

### 增量与存量：进场期与它的质量

判断行情，第一位的不是盯某个币涨跌，而是看**整个流动性蛋糕在做大还是缩水**——这对应"进场期"与"退场期"。

- **进场期（增量市场）**：蛋糕在做大，聪明钱有意愿入场，潜力标的能对标龙头跑出真正的趋势，"大饼多分少分无所谓，其他币照涨"。
- **退场期（存量市场）**：蛋糕在缩水，主力已在撤离，"大饼一涨就意味着别的都得跌"，基本没有大趋势、只有震荡。**退场期第一天起，无论基本面多好都绝不建仓、坚决离场。**
- **进场期还分"质量"**：优质进场，是场外资金先慢慢积蓄、引导场内；劣质进场，是场内游资情绪先行、场外被迫跟随、"随时想跑"，于是涨一段就被"一根针扎下去"打断。看清质量，就不必为"上不上车"焦虑——劣质进场的涨，不是好机会。
- **有增量的地方才有真机会**。在存量里争夺是零和博弈，天生已错了一半——最好的状态是"无敌"（没有对手），而非击败对手。把注意力放在增量赛道和完善自我上。

### 交易的世界观：先求不败，再图胜利

场外指数体系再强，也只是"概率体系"（擅长猜顶）；它必须配上"交易结构"（把亏损锁死），两把剑合璧才算大成。而交易结构的底层，是一整套心法：

- **以正合，以奇胜；先求不败，再图胜利**。"只要你的注意力放在'赢'上，你已经输了一半。"先用结构锁死亏损，让利润无限奔跑，战略天平的大头就已到手。
- **结构 > 对行情的判断**。交易像织一张绵密的渔网：结构对了，哪怕看错行情也亏不大；网上有洞，鱼再多也全从洞里跑光。真正的从容，是"布好网、睡一觉再收鱼"，而不是"拿着枪去追兔子"。
- **主动权 = 浮盈**。浮盈在手，怎么走都从容；一旦浮亏，主动权就交到了对手手里，自己成了砧板上的鱼肉。正确的操作，从第一单起就应该是盈利的——这也是"越涨越买"的滚仓优于"越跌越买"的抄底的根本原因。
- **保住本金，是复利的前提**。复利的关键不在年化多高，而在**本金不亏**、在保住整条交易曲线的"凸性"——`1.1` 的 100 次方是很大的数，`0.99` 的 100 次方几乎归零。**次数不重要，每一次的底数不能低于 1。** 只要不下牌桌，把正反馈循环运转到极致就够了。
- **真正的复利，是认知与方法论的复利**。它比资金复利重要得多：在潜力区里，你每天都在经历别人一年才走完的行情，迭代速度碾压长线者；小周期练出的盘感，可以无缝迁移到大周期、乃至其他市场。
- **睡得安稳是一条硬指标**。如果一段行情让你恐惧到失眠，那本身就说明结构有问题——好策略让你能安心地该做什么做什么。

### 顶部不可预测：按时间止盈，而非点位

"买入是徒弟，卖出是师傅"——建仓容易，止盈才是真功夫。而止盈的第一原则是：**不要试图预测顶部。**

- **你的想象力，永远赶不上市场的想象力**。"连操盘手自己都猜不到顶在哪，你怎么可能知道？"用预设点位去抄底或封顶，主动权都不在你手里。
- **所以按"时间"止盈，而非按"点位"**：底部可以从场内信息推出，但高点常常无法预测——因此把中期止盈锚定在场外指数给出的"退场期第一天"，这是多年验证最稳的一招。
- **这是一种贝叶斯式决策，而非刻舟求剑**：不预设"几月几号见顶"，而是每天吸收新信息、动态更新概率，"脚踩西瓜皮，滑到哪里算哪里"——到了那个点，体系自然会告诉你"这就是顶"。
- **同一个止盈指引，对不同人应有不同用法**：性格保守的一见减速信号就走，见过大风浪的能等到最后。拿不住的利润，哪怕吃到了也对你没有意义——所以允许这种多样性，才是负责任的指引。

### 为什么这套体系从不做空

体系里放进潜力区的标的，多头**向量非常纯净**——推动它的力量单一、行动主体少，方向可预测。而做空最肥美的区间（顶部下杀），力量极其不纯净：既有主力、又有大量抄底散户，如同三体般混沌，根本无法预测。"同样一个原因可以生出不同结果"——同一只野庄股，对别人是做空的理由，对纪律严明者却是远离的理由。**尤其是靠叙事驱动的题材股，一条推文就能改变叙事、迎来暴涨，做空它无异于找死。**

### 常见的认知陷阱

- **抄底**：上升趋势里做多，只有买在最高点那一个点会错；下跌趋势里做多，只有买在最低点那一个点才对。**抄底，本质是在下跌趋势里赌那唯一正确的点**——概率上极端错误，很多人是"抄底抄死的"。
- **比价思维**："比特币涨了以太坊一定跟上""金银比 1:3、白银该补涨""美光涨了海力士必涨"——这类固定比价推演是最危险的思维毒药，让人越浮亏越加仓。**涨不涨从来是主力说了算，不是比价说了算**。真正的信号恰恰相反：龙头暴涨进场、某标的却迟迟不动，在场外体系里是**主力弃守的劣势信号**，不是"补涨"机会。
- **浮亏加仓（变相马丁格尔）**：网格、越跌越补、拉低成本，靠扛单扛出来的高胜率，早晚死无葬身之地。**日常大部分时间都在浮亏，本身就说明操作有问题。**
- **和所有人站在一边**：如果你的判断和所有人都一样，这个判断就没有任何溢价。**没找到对手盘，对手盘就是你自己——你就是被收割的流动性、是燃料本身。** 真正的趋势，往往和大众的一致预期相反。
- **机会匮乏感下改结构**：退场期不肯走、硬要追某个机会，往往是"机会匮乏感"在作祟。而一旦为追行情临时改结构，新结构必然和绝大多数散户站在同一位置。潜力区里每天都有机会，不必为一个机会扭曲自己的结构。
- **求圆满 = 傲慢 = 爆仓的伏笔**：一盈利就觉得自己"悟道"、是市场本身，这种傲慢会让人不再敬畏市场、让仓位偏离体系。真正的态度是永远自我批判、日日更新——行动只有两种结果：要么拿到盈利，要么更新认知，所以**在理性框架下，永远是赚的**。

### 信息源的比例感

交易是一件极度贴近客观事实的事，它对"比例感的中正"有严格要求。**你摄入什么样的信息源，很大程度上决定了你的操作是否合乎客观。**

- **用资本市场当尺子来校准信息源**：交易与资本领域是最贴近客观事实的地方——如果你的判断与真金白银定价反复背离，该反思的往往是自己的信息源，而不是市场。
- **拒绝"先有观点、再找证据"**：让客观数据以它本该有的比例映射进你心里，不断扩大自己的信噪比；对那些反复带偏你比例感的声音，要勤于取关、勤于拉黑。"兼听则明"是信息高度匮乏时代的成语——在信息过载的今天，筛选比广纳更重要。

### 这套认知的边界

把市场简化为"两庄 + 散户"的博弈，是一个有用的入门视角——散户处在消息滞后、易受情绪影响的位置，只有跟着场外资金的脚步，才能逆转被收割的宿命。但这个框架有**明确的失效场景**，必须诚实对待：

- **两个对等强庄的持续互殴**（如同时被基本面派与题材想象派当作战场的标的），价格会退化成无规律的布朗运动，场外体系并不适用——这种"真三方混战"的标的，反而应当远离。
- **个股噪音过大的市场**（如 A 股个股，主力难以真正锁仓、"八个人八个想法"），信号极乱。此时应上移到**赛道 ETF** 层面，用赛道的宏观确定性过滤掉个股的随机扰动。

一句话：**这套认知帮你在有序、有增量的战场上占据主动；而当战场退化为纯粹的随机混战时，最好的认知就是识别它、并选择不参与。**

## 三、场外体系的实际用法

Mag场外体系用最简单的数据，快速看懂市场背后的资金行为和主力意图。

### 1. 对标链的理解 🔗

把市场想象成一条"对标链"：

```
美股纳指 (顶层)                        国内A股 (独立体系)
    ↓                                 ↓
比特币 (BTC)                          国内人工智能
    ↓                                 国内机器人
龙头币 (ETH, BNB, SOL, DOGE 等)        等...
    ↓
小币种 (其他山寨币)
```

**说明**：
- 加密货币遵循：美股 → BTC → 龙头币 → 山寨币 的对标链
- 国内A股（包含"国内"、"A股指数"、"沪深"、"上证"、"深证"等关键词）：与美股、BTC平级，不参与对标验证
- 国内A股只应用基础修正（相变、爆破、逼近），不应用对标链修正

**操作原则**:
- 无论交易哪个币，优先判断**对标链更上层**的行情
- 美股和比特币表现好 + 龙头币同步共振 → 再考虑目标币
- 如果上游出问题（美股或BTC资金退场）→ 即使小币很强也要谨慎
- **顶层的"水龙头"关了，下游再努力也难持续**

### 2. 如何比较关键节点 📊

场外体系里，每一次进场或退场，都有重要的**参照节点**。

#### 进场期第一天
必须和以下两者中**时间更近**的节点对比：
- 最近一次**爆破指数跌破200**
- 前一次**进场期第一天**

目的：对比本轮开始时资金质量

#### 退场期第一天
必须和以下两者中**时间更近**的节点对比：
- 最近一次**爆破指数负转正**
- 前一次**退场期第一天**

目的：看资金撤离的速度和质量

> **为什么"进退场第一天"如此关键？** 因为它对应体系里最核心的一条纪律——**按时间止盈，而非按点位止盈**。底部可以从场内信息推出，但顶部常常无法预测（"你的想象力永远赶不上市场的想象力"）；与其去猜某个价位，不如把中期止盈锚定在**退场期第一天**这个时间节点上。这正是第二章「顶部不可预测」的落地：不预设点位，让体系随每天的新信息动态更新，到点自然会告诉你该走了。

#### 插值计算
如果两个关键节点不在同一天，需要用**线性插值法**推算。

**示例**：
```
10.10: 场外指数 1200, 爆破指数 220
10.11: 场外指数 800,  爆破指数 180

需要估算爆破指数正好跌破200时的场外指数：
场外指数@200 = 1200 + (800-1200) × (200-220)/(180-220)
              = 1200 + (-400) × (-20)/(-40)
              = 1200 - 200
              = 1000
```

### 3. 特殊情况：相变值的处理 ⚡

场外指数有个**"相变线"** - **1000分界**。

如果关键节点一个在1000以下、一个在1000以上（如 980→1010），这种跨越意味着：
- 行情效率切换很大
- 主力意愿切换很大

**处理方式**：
- 正常涨幅外，额外加上 **+5% 补偿**
- 确保这种质变不会被低估

**示例**：
```
980 → 1010
表面涨幅 = (1010-980)/980 × 100% = 3.06%
相变补偿 = +5%
最终涨幅 = 3.06% + 5% = 8.06%
判定结果 = 优质进场 ✓
```

### 4. 波动质量的量化 📈

所有对比都可以量化判断行情是否"优质"。

| 最终百分比 | 质量评级 | 操作建议 |
|-----------|---------|---------|
| > 5% | **优质** | 勇敢操作，可以重仓 |
| -5% ~ 5% | **一般** | 谨慎灵活跟进，轻仓试探 |
| < -5% | **劣质** | 小心止盈，减少操作 |

**质量判定公式**：
```
最终百分比 = 基础涨幅 + 相变修正 + 美股修正 + 爆破指数修正 + 逼近修正
```

**各项修正说明**：
- **相变修正**: 跨越1000分界线 → ±5%
- **美股修正**: 美股退场期 且 币种进场期 → -10%
- **爆破指数修正**:
  - 进场期第一天 且 爆破>200 → -2.5%
  - 退场期第一天 且 爆破<0 → -2.5%
- **逼近修正**: 当日有"逼近"标记 → -5%

### 示例7: 插值计算的退场期 (完整流程)

**数据**:
```
日期: 2025-04-20
币种: ETH
当前状态: 退场期第1天
场外指数: 555
爆破指数: -29

前一天 (2025-04-19):
场外指数: 740
爆破指数: 114

参考节点查找:
2025-04-15: 场外指数 680, 爆破指数 -10
2025-04-16: 场外指数 820, 爆破指数 35 ← 负转正发生在这两天之间
```

**步骤1: 插值计算参考节点场外指数**
```
爆破指数从 -10 → 35，跨越 0

场外指数@0 = 680 + (820-680) × (0-(-10))/(35-(-10))
            = 680 + 140 × 10/45
            = 680 + 31.11
            = 711.11
```

**步骤2: 计算基础涨幅**
```
基础涨幅 = (555-711.11)/711.11 × 100% = -21.95%

退场期反向计算:
实际涨幅 = -(-21.95%) = +21.95%
```

**步骤3: 应用修正**
```
相变修正 = 0 (555 < 1000, 711 < 1000)
美股修正 = 0
爆破指数修正 = -2.5% (退场期第1天 且 爆破-29 < 0)
逼近修正 = 0

最终百分比 = 21.95% + 0 + 0 + (-2.5%) + 0 = 19.45%
```

**判定结果**: **优质退场期** (> 5%)

**重点说明**:
- 退场期的基础涨幅要反向计算
- 插值计算确保了参考节点的精确性
- 爆破指数为负值时触发修正，警示市场极度冷却

### 核心算法

#### 1. 关键节点检测
```python
# 进场期第一天：phase_days == 1 且 phase_type == '进场期'
# 退场期第一天：phase_days == 1 且 phase_type == '退场期'
# 爆破跌破200：前日 >= 200 且 当日 < 200
# 爆破负转正：前日 < 0 且 当日 >= 0
```

#### 2. 插值法计算
```python
# 计算爆破指数=200时的场外指数
场外指数@200 = 前日场外指数 +
               (当日场外指数 - 前日场外指数) ×
               (200 - 前日爆破指数) /
               (当日爆破指数 - 前日爆破指数)
```

#### 3. 质量判定公式
```python
最终百分比 = 基础涨幅 + 相变修正 + 美股修正 +
             爆破指数修正 + 逼近修正

# 相变修正：跨越1000分界线时 ±5%
# 美股修正：美股退场期且币种进场期时 -10%
# 爆破指数修正：
#   - 进场期第一天 且 爆破指数>200: -2.5%
#   - 退场期第一天 且 爆破指数<0: -2.5%
# 逼近修正：当日有逼近标记 -5%

质量评级:
  > 5%: 优质
  -5% ~ 5%: 一般
  < -5%: 劣质
```

#### 4. 进退场期反向逻辑 (v2.3.0)

**进场期**：
- 场外指数变高 → 涨幅为正
- 场外指数变低 → 涨幅为负
- 跨越1000向上 → 相变修正 +5%
- 跨越1000向下 → 相变修正 -5%

**退场期**：
- 场外指数变高 → 涨幅为负（反向）
- 场外指数变低 → 涨幅为正（反向）
- 跨越1000向上 → 相变修正 -5%（反向）
- 跨越1000向下 → 相变修正 +5%（反向）

#### 5. 对标链验证
```
小币进场条件：
  ✓ 美股进场期
  AND ✓ BTC进场期
  AND ✓ 所有龙头币进场期

龙头币进场条件：
  ✓ 美股进场期
  AND ✓ BTC进场期

BTC和美股：
  始终通过验证
```
